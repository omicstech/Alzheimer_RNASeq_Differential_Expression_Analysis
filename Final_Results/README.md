# Alzheimer RNA-Seq Differential Expression Analysis

## Project Overview
This project performs differential expression analysis on Alzheimer's disease RNA-Seq data to identify significant gene changes compared to control groups.

## Analysis Summary
- **Mapping:** High-quality reads aligned to the reference genome.
- **Differential Expression:** Statistical analysis performed to identify up-regulated and down-regulated genes.
- **Annotation:** Ensembl IDs converted to Gene Symbols using AnnotationDbi.

## Visualizations
- **Volcano Plot:** Visual representation of log2 fold change and adjusted p-values.

## Files
- `final_results_with_symbols.csv`: Comprehensive list of differential expression results.
